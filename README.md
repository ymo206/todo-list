
# Simple To-Do List

A simple web application for keeping track of school assignments and daily tasks.

## Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Save tasks automatically

## Technologies
- HTML
- CSS
- JavaScript

## How to Use
Once the application is built, open index.html in a web browser.
